# My Portfolio

## About

A simple, responsive personal portfolio website for Karthikeyan B, a first-year Computer Science student at Scaler School of Technology. Built for Builders Day.

## Technologies

- HTML5 (semantic tags)
- CSS3 (`style.css`: smooth scroll, keyframe animation, focus styles)
- Tailwind CSS via CDN (most of the layout and styling, used for the bonus point)
- No JavaScript is used for the site's behaviour

## Sections

Navbar, Hero, About, Skills, Education, Projects, Experience, Contact, Footer.

## Projects

### Student Portal

### Flexbox Quest

A game-styled Flexbox practice page with a HUD, game area, on-screen controls, inventory grid, quest tracker and Display Lab.

## How to run

Open `index.html` in a browser. An internet connection is needed because Tailwind is loaded from a CDN.
